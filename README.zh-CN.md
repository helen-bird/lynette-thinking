**What would Lynette do?**

一个受《绝望主妇》Lynette 启发的 AI Skill，陪你处理现实困境：理解发生了什么，决定怎么做，开口沟通，再把行动推进下去。

## 带来你想处理的问题

| 你卡住的地方 | 可以这样问 |
| --- | --- |
| 职场 | “老板之前同意招人，现在又开始质疑必要性。我该怎么推进？” |
| 家庭 | “妈妈每周需要我帮忙好几次。怎么既满足实际需要，又让我能长期承担？” |
| 朋友 | “朋友总是临时取消。我还想见她，但不想一直为落空的约定留出晚上。” |

从你知道的部分开始。默认先用简短的大白话说清当前最值得做的一步，必要时给一句能直接使用的话；需要详细讨论时再展开。试过之后，带着实际回应回来，继续处理新的卡点。

## 借用她看问题的角度

Lynette 会注意什么条件让一种安排持续下去。老板拒绝停止办公室打赌，她就利用老板愿意接受挑战这一点，把停止以后的打赌谈进条件里。常规渠道找不到合适保姆，她把企业猎头的办法搬进家庭招聘。

Skill 从这些选择中提炼思路：查清为什么对方总选你，看看哪些条件可以改变，到惯常渠道之外找资源，并让谈成的安排真正运转起来。她的误判和改口也保留其中。一个聪明主意，仍要适合你的处境，并经得住后续的实际反馈。

## 看一次对话怎样推进

*以下为使用演示，节选自[职场示例](skills/lynette-thinking/examples/guided-resolution.zh-CN.md)。*

> **你：** 老板说只有我能整合四个团队的周报。谁晚交，我还得替他写。
>
> **Skill：** 哪部分需要你的判断：收集、补写，还是检查内容矛盾？先请老板说清楚，再谈怎么分工。
>
> **你：** 他担心口径冲突。同事可以收集，但她催不动所有团队。
>
> **Skill：** 提议试一周：她收集，你检查矛盾，各团队写自己的内容。请老板确认谁处理迟交，避免你再次自动成为补写的人。
>
> **你：** 最后老板自己去催了，我们按时发出。下周还没说定。
>
> **Skill：** 这套安排成功落实了一次。下一步确认下周是否继续，包括谁负责处理迟交。

## 安装，然后自然提问

在 Codex 中使用：下载并解压仓库，在仓库根目录用 Python 3.9+ 运行：

```sh
python3 scripts/install.py
```

安装脚本只复制本地文件，遇到已有安装会停止。[手动安装与更新方式](docs/install.md)

直接描述困境，或明确指定：

> 请用 $lynette-thinking 帮我想下一步。我已经试过……，对方回应……，我想改变的是……

不必每次点名 Lynette；自动选择取决于你使用的助手和模型。执行后把结果带回对话，它就能继续帮你处理下一步。[使用说明](skills/lynette-thinking/README.md)
