# 使用 Lynette Thinking

[English](README.en.md) · [她怎样选择](references/decision-profile.md) · [核心指令](SKILL.md)

**What would Lynette do?** 从已知的部分讲起：你想改变什么，现在卡在哪里？它借用 Lynette 在具体情境中注意什么、想保住什么、怎样行动和改口，帮助你看清问题、作出选择，再按实际结果继续推进；不需要你扮演她。

## 可以自然开始

职场、家庭、朋友关系中，只要你需要决定怎么做或怎么开口，就属于匹配范围。不必写角色名。自动选择取决于使用的宿主和模型；明确指定可写：

> 请用 $lynette-thinking 帮我想下一步：我已经试过……，对方回应……，我最想改变的是……

不必先交代完整关系史。最近发生什么、对方的原话、你想改变什么、已经试过什么，知道几项就够开始。默认随你的语言回答，可引用全八季；当次说明剧透范围也会遵守。

## 它会先判断什么

| 你卡住的地方 | 借人物视角检查的区别 |
| --- | --- |
| 经验或能力没有被看见 | 缺能力证据、参与位置，还是正式资格？不同缺口需要不同动作 |
| 总被放在吃亏的位置 | 对方为什么偏偏选你，认可什么承诺或规则？ |
| 原方案找不到资源 | 不可替代的功能是什么，哪些来源只是被惯例排除了？ |
| 想接受帮助又怕受控 | 困难在资源本身，还是双方的角色、贡献和决定权？ |
| 想替别人安排才安心 | 哪些负担真实，哪些判断沿用了旧关系？新事实是否要求撤回干预？ |

人物的具体性来自这些有条件的偏好，也来自她[从问题发生到结果的过程](references/problem-solving-journeys.md)：怎样打听、沟通、行动、遇阻与改口。这不是给你逐项回答的问卷。助手按需读取相关资料和少量案例；她的误判也保留，避免把机灵等同于无代价的正确。

## 先有起点，再补必要信息

默认先用简短的大白话说当前最值得做的一步，必要时给一句能直接使用的话。需要细化、比较或演练时再展开；你可以直接说“详细一点”或“帮我把消息写出来”。给你的解释和写给老板等人的消息，会按各自场景调整语气。

你通常先得到一个做得动的起点，包括一个动作、必要时一句能说出口的话、为什么对方可能接受，以及不成时的退路。助手会区分已知事实与推测，补问最可能改变决定的信息；信息需要从别人那里获得时，也可以先帮你想清楚问谁、怎么问。

开局每轮通常只问一项，确有独立作用时最多两项；同一决策最多主动澄清两轮。够用就进入行动，不要求你先回答完整清单。你可以直接说“先按现有信息给建议”“这条我不知道”或“不要继续追问”。

涉及工时或钱，会分清个人与团队、每人每期与总额，不把未知份额当承诺；期限放宽也会提前准备最后执行窗口所需的资源。建议应适合你当下能承担的时间、资源和关系代价，必要时先缩小一步。

## 试过以后，带着结果回来

你可以继续说：

- “他没有决定权，真正拍板的是另一个人。”
- “他答应了，但到约定时间还没做到。”
- “先试了两天，工作量反而更多了。”
- “这一部分解决了，现在卡在另一个条件。”

助手会先核对发生了什么、原目标还有多大差距，再决定保留、调整或更换行动。开局两轮澄清的上限不意味着你带回执行结果后必须停止；后续每次只补当前最关键的缺口，继续处理下一障碍。

开始试行、获得口头同意和稳定达到目标，是不同进度。收尾时对照你原本希望改变的事，确认已有结果、剩余问题和还需要观察的部分；目标改变时先与你确认。未解决的部分会明确保留，不把暂时缓和当作已经解决。你也可以选择暂停或接受一个已说明的取舍。

[多轮推进示例](examples/guided-resolution.zh-CN.md)是为解释用法设计的演示，其中的人物和反馈均为虚构。[推进参考](references/guided-resolution.md)说明怎样把理解、选择、行动、反馈与收尾连起来。

## 用人物洞察，不照搬剧情代价

[决策片段](references/decision-episodes.md)分开记录发生了什么、角色明确的目标、研究解释和后果。她可能冒险、控制局面或误判；现实建议会另行判断采用、改造还是舍弃。

[正反例校准](references/contrast-cases.md)展示：为什么一个礼貌、合理的答案可能丢掉关键转折；也说明何时应该放弃类比。常规办法足够时不强求奇招，不要求你赢得所有人的认同。

## 按需要深入

- [判断偏好](references/decision-profile.md)：什么情境会改变她的注意、目标和取舍。
- [完整问题处理过程](references/problem-solving-journeys.md)：在现有案例中跟随信息、行动、反馈与结果，保留未解决的部分。
- [决策片段](references/decision-episodes.md)：跟随具体情境中的目标、选择、行动与后果。
- [具体行动机制](references/strategic-moves.md)：挑战换规则、改变被选择的收益、扩展资源和互惠结构。
- [职场](references/workplace-cases.md)、[家庭与朋友](references/relationships-cases.md)、[S3–S4](references/later-seasons-3-4.md)、[S5–S6](references/later-seasons-5-6.md)、[S7–S8](references/later-seasons-7-8.md)：详细来源与后果。

继续推进依靠你把执行结果带回对话；Skill 本身不自动保存跨对话记忆、安排提醒、联系他人或替你执行，也不能保证他人的回应和现实结果。只想倾诉时说“先听我说”，已有决定只需润色时说“保留决定，只改文字”。人物案例可以拓展问题，不能替代需要专门事实依据的安全、医疗、法律或重大财务判断。
