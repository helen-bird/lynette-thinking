# Skill 如何构建

[English](development-method.en.md) · [人物资料来源](evidence.md) · [首页](../README.zh-CN.md)

起点是 Lynette 在《绝望主妇》中作出的一个具体选择：她注意到什么，想保住什么，向谁打听，改变了什么，后来又发生了什么。Skill 会沿着这个过程走到行动及其后果。

## 跟随完整的问题过程

[问题处理过程](../skills/lynette-thinking/references/problem-solving-journeys.md)跟随信息获取、协商、资源、执行、反馈与纠正。[决策片段](../skills/lynette-thinking/references/decision-episodes.md)分开记录剧情事实、角色明确说出的目标，以及我们对机制的解释。行动最终的结果，不代表她事先预见了所有后果。

## 保留招数背后的人

[判断偏好](../skills/lynette-thinking/references/decision-profile.md)保留她的职业愿望、竞争心、对等诉求和接管冲动。她的错误同样有用：熟悉一个人可能变成替对方决定，接受帮助也可能带来新的权力关系。这些张力帮助判断一种做法何时适合。

[正反例](../skills/lynette-thinking/references/contrast-cases.md)说明哪些细节会改变判断。[具体动作](../skills/lynette-thinking/references/strategic-moves.md)再帮助把判断变成行动，例如改变承诺形式、查清为什么总被选中，或组合几种较小的支持来源。

## 把洞察转化为用户的下一步

助手从用户的目标、当前障碍、已知事实与限制出发，先给一个做得动的起点，再补问可能改变决定的信息。如果信息在对话之外，就帮助确定问谁、怎么问。

可用的方案需要有执行者、可获得的资源、对方可能接受的理由，以及用户能承担的代价。人物的动作可以在现实中采用、改造或舍弃。常规方法管用时就可以用，创新并非每次都必需。

用户带着执行后的情况回来时，[推进指南](../skills/lynette-thinking/references/guided-resolution.md)帮助把反馈接回原目标和下一个障碍。提议、同意、试行与持续有效是不同进度。改变目标需要先得到用户同意。
